Working with Definition List

HTML
HTML is an Acronym that means HyperText Markup Language. It is the Basic Language of the World Wide Web. It is Used in Creating the Structure of the Web. It is made up of tags. tags are made up of angular braces with a special word that performs a specific task or creates a specific structure. To be a web developer you should understand HTML very well.
CSS
CSS means Cascading Style Sheet. It is used to Design Web Applications to make the appealing and enhance the User Experience. Without CSS Web Pages or Web Applicatiion would be very flat and boring.
